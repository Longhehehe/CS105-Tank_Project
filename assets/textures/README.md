# Texture Assets

The PBR texture maps in these folders were downloaded from ambientCG at 1K JPG resolution and are licensed under Creative Commons CC0 1.0.

- `Ground054`: muddy dirt/sand ground used for the road, mud, craters, rocks, and sandbags.
- `Ground037`: mossy/grass ground used for grass and jungle surfaces.
- `Metal063`: dark rusty metal used for tank normals/roughness and metallic parts.

`tank_camo.svg` is a small local camouflage tile created for this project.

Sources:

- https://ambientcg.com/view?id=Ground054
- https://ambientcg.com/view?id=Ground037
- https://ambientcg.com/view?id=Metal063
